# FairMoney Collection Voicebot

An **outbound AI voicebot for loan collections**, built for a Nigerian microfinance bank (Low-Risk segment). It places automated calls to customers with overdue loans, verifies their identity, communicates loan details, detects payment intent, and drives the conversation to an outcome — capturing promises-to-pay, negotiating payment dates, or transferring to a human agent when required.

> **Stack:** Asterisk (AudioSocket + FastAGI) · Deepgram STT · Azure Neural TTS · Groq LLM via LangChain

---

## Highlights

- **~100 concurrent calls**, designed for ~5,000 calls/day, ~5 min average call length
- **Nigerian English** voice (`en-NG-EzinneNeural`) with a deterministic greeting + LLM-driven dialogue
- **Guardrails over generative freedom** — deterministic regex gates override the LLM on identity verification, so a customer can never be "hallucinated" as verified
- **Full barge-in support** — LLM streaming runs concurrently with STT listening; the caller can interrupt at any time
- **Hallucination filtering** — sentence-level detection of JSON/CoT/tool-call leakage before anything is spoken
- **Per-turn persistence** — interim disposition pushed to SQLite + CRM API on every turn, plus a final push on hangup

## Architecture

```
Asterisk dialplan
   │  AGI(agi://<host>:4573/call)
   ▼
fastagi_server.py (:4573)                  audio_socket_server.py (:9092)
  ANSWER → read dialer channel vars          accepts media socket, reads UUID
  (CUSTOMER_NAME/EMAIL, DUE_AMOUNT,          pops staged customer info
   IDGCALL / IDGLEAD / IDGSERVICE)           (250 ms retry to avoid the race)
  generate AUDIOSOCKET_ID uuid                      │
  stage into pending_customer_info  ────────►       ▼
  EXEC AudioSocket <uuid>,host:9092          fairmoney_main.handle_call()
  (blocks for the whole call)                       │
  post-call: stamp ~25 CallData* vars        STT ◄─┘ audio frames
  HumanEscalation=Y → Queue("agent")              TTS → barge-in turns
  else hang up                                     LLM (Groq, tool-calling)
        │
        ▼
  disposition → SQLite + dispositions/*.jsonl + CRM API
```

Both servers run in **one asyncio process** via `run_servers.py`. A UUID generated by FastAGI links the signaling and media paths; the AudioSocket server polls up to 250 ms for the staged customer record to close the startup race.

> The bot is swapped by changing **one import line** in `audio_socket_server.py` (line 11) — the rest of the codebase is fully decoupled from any sibling project.

## Conversation flow

The prompt (`prompts/fairmoney_prompt.py`) is **marker-driven**: the system prompt emits control markers that switch script branches, and the markers are stripped before TTS.

| Marker | Meaning |
|---|---|
| `__RPC_VERIFIED__` / `__RPC_NOT_VERIFIED__` / `__RPC_CALLBACK__` | Identity verification outcome |
| `__INTENT_WILL_PAY__` / `__INTENT_NEEDS_TIME__` / `__INTENT_TRANSFER__` / `__INTENT_REFUSES__` | Payment intent branch |
| `__PTP_CAPTURED__` / `__DATE_NEGOTIATED__` | Promise-to-pay / date agreement |
| `__PAYMENT_LINK_SHARED__` / `__DISCONNECT__` | Payment link sent / call closed |

**Stages:**

1. **Greeting** — deterministic (not LLM): Lagos-time greeting + "is this \<Name\>?"
2. **RPC verification** — LLM under `INITIAL_SYSTEM_PROMPT`, but deterministic regex gates override it:
   - clear positive → verified
   - clear negative → alternate-number gate + read-back confirmation → callback
   - 2 failed attempts → deterministic close (`RPC_NOT_VERIFIED`)
   - agent request → immediate transfer
3. **Loan script** (`_build_step2_script`) — introduction, call-recording notice, DPD-aware overdue wording, amount spelled out
4. **Intent detection** → WILL_PAY / NEEDS_TIME / TRANSFER / REFUSES
5. **Branch handling** — PTP capture (amount capped at total due), payment channel/link, BVN/OTP fraud disclaimer; needs-time negotiation within a 4-day window with DPD-based consequence script; transfer or refusal → agent queue

**Loop guards:** 15-turn max · 3 empty-turn retries ("are you still there?") · 300 s call limit · 0.4 s interrupt guard · 12-sentence cap · repeat-question guard · immediate end on spoken "goodbye".

## Tech stack

| Layer | Implementation |
|---|---|
| Telephony | Asterisk — AudioSocket `:9092` + FastAGI `:4573`, asyncio, semaphore-gated concurrency |
| STT | Deepgram **Flux** (`flux-general-multi`, 8 kHz) with **Nova-3** fallback for unsupported languages |
| TTS | Azure Neural TTS (`en-NG-EzinneNeural`) — sentence-level streaming, 8 kHz PCM; Cartesia `sonic-3.5` available via `TTS_ENGINE` |
| LLM | Groq `openai/gpt-oss-120b` via LangChain, tool-calling with 9 bound tools, history summarization, retry middleware |
| Storage | SQLite + daily JSONL dispositions + transcripts |

### LLM tools

`capture_ptp` · `negotiate_payment_date` (≤ 4-day window) · `transfer_call` · `capture_refusal` · `request_callback` (11-digit NG validation) · `share_payment_link` · `record_payment_mode` · `disconnect_call` · `save_call_data`

All tools return protocol strings (`PTP:…`, `TRANSFER:…`, `CALLBACK:…`) parsed by the turn loop.

## Getting started

```bash
# 1. Clone
git clone https://github.com/harshilgithubriit/Fairmoney-voice-bot.git
cd Fairmoney-voice-bot

# 2. Configure (copy the template and fill in your keys)
copy appsetting.example.json appsetting.json

# 3. Install dependencies
py -3.13 -m venv .venv
.venv\Scripts\pip install -r requirements.txt

# 4. Run both servers (AudioSocket :9092 + FastAGI :4573)
.venv\Scripts\python.exe run_servers.py
```

Or simply run **`start.bat`**, which builds the virtual environment and launches the servers automatically.

> **Windows note:** `start.bat` is the fastest path on a fresh machine — it auto-detects Python, creates `.venv`, installs requirements, and starts the servers.

## Testing without Asterisk

A load-test harness replays a WAV file over AudioSocket and simulates multi-turn conversations, reporting connect rates and latency percentiles:

```bash
.venv\Scripts\python.exe extra\load_test_conversation.py --wav sample_8k.wav --calls 1
```

Options: `--host`, `--calls`, `--ramp`, `--call-duration`, `--greeting-wait`, `--max-turn-wait`, `--turn-gap`.

> This validates infrastructure survival under concurrency, not conversational correctness.

## Configuration

Settings load in priority order: **`appsetting.json` → `.env` → environment variables** (see `config/settings.py`).

| Key | Default | Notes |
|---|---|---|
| `Server.AudioSocketPort` | `9092` | media server |
| `Server.FastAgiPort` | `4573` | signaling server |
| `Server.MaxConcurrentCalls` | `100` | 90 channels + headroom |
| `AiServices.TtsEngine` | `azure` | `azure` or `cartesia` |
| `BusinessRules.MaxCallDurationSecs` | `300` | hard call cap |
| `BusinessRules.MaxPaymentDateDays` | `4` | negotiation window |
| `BusinessRules.TransferQueue` | `agent` | Asterisk queue for escalation |
| `ApiEndpoints.EnableCrmPush` | `true` | per-turn disposition push |

**Never commit `appsetting.json` or `.env`** — both hold live credentials and are git-ignored. Use `appsetting.example.json` as the template.
